# 《奇点熔炉》200 小时可玩性路线图

> “200 小时”是需要通过真实玩家测试校准的内容目标，不等于强制等待 200 小时。任何阶段都应至少提供三种有意义的成长方向。

## 设计边界

- 不用血量墙、离线等待或重复点击虚增时长。
- 每次 Prestige 都要解锁规则、自动化或新构筑，而不只是提高倍率。
- 单一 Build 不应长期统治所有场景；Boss、试炼和异常规则应鼓励换装。
- 旧存档必须可继续读取，新系统按阶段渐进开放。
- 静态 Web 版本不依赖服务器；排行榜留到具备可信后端时再开发。

## 阶段二：熔炉扩展（2～10 小时）

- [x] 六路线炉心永久强化矩阵
- [x] 自动技能与额外模块槽的里程碑
- [x] 主动脉冲、熔炉超载与每 10 级攻击里程碑
- [x] 共振、断裂、奇点三种机制专精与永久精通（首版）
- [x] 区段途中补给三选一、四种守卫遗物与重复强化
- [x] 八个成就、守卫/法则图鉴与三层目标展示
- [x] 镜像、时间、熵三名法则守卫
- [x] 破坏、熔炉、法则三分支科技树
- [x] 沉默、绝对时间两种五阶入门试炼（分布于 2～52 级永久守卫里程碑）
- [x] 单槽构筑预设与三种自动购买优先级
- [x] 深度 30 后无尽区段、守卫自主结算和动态炉心收益
- [x] 五种三选一区段法则
- [ ] Boss 自动换装

验收标准：这里的分钟数是累计主动游玩估算，不是计时锁。前 5 分钟持续获得升级反馈并通过深度解锁无人机；随后逐步开放自动购买与自动技能。击败深度 30 守卫后，玩家可以继续深潜并主动承担法则风险，也可以用随深度增长的收益重铸。玩家卡关时可以在永久协议、构筑调整、区段法则和试炼中至少选择两项。

## 阶段三：法则改写（10～40 小时）

- [ ] 第二层 Prestige 与法则点
- 无界暴击、超频、技能回响、递归等规则升级
- 六种完整法则试炼及分层奖励
- 超级暴击、技能触发技能、攻击触发技能
- 条件式自动重铸与构筑切换

验收标准：法则改写前后最优构筑发生明显变化；玩家从“购买数值”转向“设计循环”。

## 阶段四：奇点网络（40～100 小时）

- [ ] 奇点模式与程序化异常规则组合
- [x] 无限深度与循环法则守卫（首版）
- [ ] 分层首领词缀
- 隐藏法则、稀有模块和构筑图鉴
- 自动化规则编辑器
- 本地赛季档案与个人纪录

验收标准：相同资源量下，不同异常规则需要不同构筑；至少三类终局目标可并行推进。

## 阶段五：超越层（100～200 小时）

- 法则星图：跨周目选择互斥路径，完成后可逐步全部掌握
- 奇点契约：玩家主动叠加限制换取专属规则奖励
- 模块共鸣套装：由模块组合产生新行为，不增加无意义装备数量
- 构筑精通：以特定机制达成目标，而非单纯累计在线时间
- 动态终局任务：从已解锁规则中生成可复现的挑战种子

当前完成了留存核心、无尽深潜、三流派机制、补给和永久收集闭环，并显示离线回收。第二层转生、完整剧情/音效、种子挑战和 200 小时平衡仍未完成；现有系统需要真实试玩继续校准。

验收标准：100 小时后仍有新规则组合出现；任何 30 分钟游玩段都能完成一次明确决策或目标，不能只剩挂机。

## 平衡验证

- 使用确定性模拟检查 30 分钟、2 小时、10 小时、40 小时、100 小时节点。
- 每个阶段记录普通敌人、Boss、重铸和法则改写的中位耗时。
- 自动化收益不得超过主动优化后的合理上限，离线收益不得成为唯一最优解。
- 每新增一项机制，都为存档迁移、上限条件和相互作用补充回归测试。
