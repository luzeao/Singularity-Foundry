# 《奇点熔炉》Web MVP 设计

## 目标

制作一个无需安装、可直接在现代浏览器中试玩的 1～2 小时 MVP。玩家应能在打开页面后立刻看到自动战斗，通过升级、技能与模块形成构筑，击败三个区域的法则节点与最终 Boss，并至少完成一次能显著加速后续流程的重铸。

## 范围

MVP 包含：

- 三个区域：物质层、重力井、热寂边界；每区 10 个节点。
- 一个拥有阶段机制的 Boss：重力守卫。
- 自动基础攻击、攻击力、攻击速度、暴击与资源倍率。
- 三个自动技能：过载、奇点炮、时间折叠。
- 六个可切换模块，最多装备两个；模块强调规则变化而非小数值。
- 十二种升级，按进度逐步显露，支持单次与批量购买。
- 第一次 Prestige“重铸”，奖励炉心碎片并解锁基础自动购买。
- 引导任务、下一解锁提示、战斗日志、数值解释器、存档与离线收益。

不包含科技树、法则改写、挑战、排行榜、服务端或付费功能。这些属于后续试玩验证后的阶段。

## 核心循环与节奏

游戏从自动攻击开始。普通节点目标击杀时间控制在约 0.5～5 秒；玩家每隔几十秒能买到升级或解锁新内容。区域 1 引出攻击速度和暴击，区域 2 引出技能与模块，区域 3 形成首次 Build 选择并通往 Boss。首次重铸目标为 45～90 分钟，但调试模式可加速验证完整循环。

重铸清空熵晶、普通升级、当前敌人和区域进度，保留技能与模块解锁、炉心碎片和永久里程碑。炉心碎片提高全局伤害与资源倍率；累计获得 10 枚后解锁自动购买。重铸预览始终显示预计收益与重启后的永久倍率。

## 战斗与构筑

逻辑使用固定时间步进。基础攻击按攻击间隔结算；暴击等级由暴击率的整数层与余数决定，使超过 100% 的规则能在模块条件下被体验。技能按各自冷却自动施放，时间折叠直接缩减其他技能剩余冷却。

六个模块分别支持：攻击次数触发共振、暴击回响、暴击缩短技能冷却、技能击杀回收冷却、超额攻速转技能伤害、低频爆发。玩家可随时切换，界面同步显示当前主要 Build 倾向。

Boss“重力守卫”随连续命中获得易伤层数，同时每 12 秒释放重力脉冲削减该层数，鼓励稳定攻速。战斗超过 45 秒时显示升级或重铸提示，而不是让玩家无提示等待。

## 状态与数据流

纯函数游戏核心保存在 `src/game.js`：创建状态、派生属性、购买、装备、推进时间、重铸、序列化与离线结算。浏览器层 `src/app.js` 只负责定时推进、事件绑定和渲染。这样所有关键规则均可用 Node 内置测试器验证。

存档写入浏览器本地存储，并带版本号。无效或旧存档回退到新游戏，不阻断启动。离线收益按前 8 小时 80%、8～24 小时 50%、24 小时以后 20% 的分段效率结算，最多计算 72 小时。

## 界面

首屏是游戏本体而非宣传页：顶部显示区域、资源与短期目标；左栏显示核心属性与倍率解释；中央展示熔炉、当前法则节点、生命条及战斗反馈；右栏以标签页组织升级、技能和模块；底部提供区域、重铸与日志。

视觉采用深空黑底、冷白文字、紫色与琥珀色能量高光，几何线框表现法则节点。熔炉核心随阶段增加环层与脉冲强度。桌面端为三栏，窄屏自动变为单栏，不出现横向滚动。按钮、进度和标签提供键盘焦点与辅助文本，重要状态不只依赖颜色。

## 验证标准

- 初始状态会自动攻击并能击杀首个节点。
- 购买升级会正确扣费、增长价格并改变派生属性。
- 暴击、三个技能、六个模块及 Boss 规则均有可观察效果。
- 第三区 Boss 可被击败，重铸收益可预览并正确重置/保留状态。
- 存档往返、无效存档恢复和离线收益有自动测试。
- 桌面与手机宽度下核心操作可见、无水平溢出；页面可通过本地 HTTP 访问。
