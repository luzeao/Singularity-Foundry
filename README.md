# 奇点熔炉（Singularity Foundry）

一款以 Build 构筑、自动化和规则突破为核心的浏览器增量游戏。玩家通过主动脉冲与自动攻击摧毁法则节点，收集熵晶，组合升级、技能和模块，并通过重铸获得永久成长。

## 当前内容

- 自动战斗与可点击的主动脉冲攻击
- 攻击、攻速、暴击、资源等升级路线
- 主动技能、规则模块与 Build 组合
- 三个区域、法则节点和重力守卫
- 重铸、永久成长、自动购买与离线收益
- 本地存档与响应式页面

## 本地试玩

需要 Node.js 20 或更高版本。

```bash
node serve.mjs
```

启动后访问：<http://127.0.0.1:4174>

## 运行测试

```bash
node --test tests
```

## 项目结构

- `index.html`：游戏页面结构
- `styles.css`：视觉样式与响应式布局
- `src/game.js`：战斗、成长、存档和离线收益逻辑
- `src/app.js`：页面渲染与玩家交互
- `tests/`：游戏逻辑、流程与界面回归测试
- `.md`：完整游戏设计文档
