# 奇点熔炉（Singularity Foundry）

一款以 Build 构筑、自动化和规则突破为核心的浏览器增量游戏。玩家通过主动脉冲与自动攻击摧毁法则节点，收集熵晶，组合升级、技能和模块，并通过重铸获得永久成长。

## 当前内容

- 前期由主动脉冲起步，推进到深度 12 后解锁脉冲无人机自动攻击
- 主动脉冲积累熔炉超载，触发 10 秒伤害与熵晶爆发
- 攻击、攻速、暴击、资源等升级路线
- 主动技能、规则模块与 Build 组合
- 三个主题区域循环生成，深度 30 后每 10 层出现一名轮换法则守卫
- 守卫胜利后可自主选择“立即重铸”或从三项区段法则中选择一项继续无尽深潜
- 质量坍缩、静默协议、绝对时序、镜面回路、熵适应五种风险法则会改变构筑并提高收益
- 炉心收益按最高深度、守卫连胜、法则风险和永久协议动态增长，不再每轮固定约 12 枚
- 重铸追赶旧区域、六路线炉心永久协议、扩展模块槽与自动技能
- 三分支科技树，以及跨重铸连续完成的沉默、绝对时间五阶试炼
- 分阶段解锁自动攻击、自动购买、自动技能，包含三种购买优先级和一个构筑预设槽
- 离线收益、移动端快捷操作和移动端单屏守卫结算
- 本地存档与响应式页面
- 深度 12 开放共振引擎、断裂处决、奇点编译三种专精，装备对应模块才能生效；可在守卫结算时切换
- 深度 15/25/35…出现三选一补给：本段伤害、熵晶收益、立即封存炉心；不会强制打断挂机
- 四种守卫保证掉落专属遗物，重复击破逐阶强化；三流派精通和法则图鉴跨重铸保留
- 「探索」「图鉴」页包含八个可领取成就，眼前、本轮、长期三层目标，以及可关闭的离线回收提示

本版增加的是可持续构筑与收集闭环，不以拉长等待或简单加血量充当内容。实际长期可玩时长仍需试玩平衡验证，不能把 200 小时目标当作已验证结果；第二层转生、完整剧情和音效仍属于后续路线。

## 本地试玩

需要 Node.js 20 或更高版本。

```bash
node serve.mjs
```

启动后访问：<http://127.0.0.1:4174>

## 运行测试

```bash
node --test tests
```

## 项目结构

- `index.html`：游戏页面结构
- `styles.css`：视觉样式与响应式布局
- `src/game.js`：战斗、成长、存档和离线收益逻辑
- `src/progression.js`：连续深度、区段法则和安全数值缩放
- `src/content.js`：流派专精、途中补给、守卫遗物、永久成就与目标
- `src/app.js`：页面渲染与玩家交互
- `tests/`：游戏逻辑、流程与界面回归测试
- `.md`：完整游戏设计文档
- `docs/ROADMAP-200H.md`：从当前版本扩展到 200 小时目标的开发路线
